# Ozane Accounts — web version

These are the built files of the Ozane Accounts web app (Tayba Perfumes), published with GitHub
Pages so staff can use the app from a phone browser, plus the app's privacy policy.

- App: https://rashidrashi7818-byte.github.io/ozane-app/
- Privacy policy: https://rashidrashi7818-byte.github.io/ozane-app/privacy/

Signing in needs an account created by the business owner; there is no public sign-up. All
business data lives in a private database with per-user access rules. The application source
code is kept in a separate private repository.
